#  Music Playlist Manager

This is a simple Python console application that allows users to create and manage music playlists.

## Features
- Create new playlists
- Add songs to playlists
- View all playlists
- Edit existing playlists
- Remove songs
- Rename playlists
- Input validation

## Technologies Used
- Python 3
- Git
- GitHub

## How to Run
Clone this repository:

```bash
git clone https://github.com/monteiroyasmin1112-a11y/Music-Playlist-Manager.git
```

Open the project folder and run:

```bash
python main.py
```
